# 🎮 Guessing Game (Python)

This is a simple terminal-based number guessing game built in Python. You guess whether the next number will be greater or smaller than the current one.

## 🚀 How to Play

- The game shows you a number between 1 and 10.
- You guess whether the next number will be:
  - **Greater (G)** — equal or higher
  - **Smaller (S)** — equal or lower
  - **Quit (Q)** — to exit the game
- If you're right, your score increases.
- If you're wrong, your score resets to 0.
- Have fun!
